﻿# ChangeLog - FileEncryptor GUI (Qt6 / Linux)

本文件记录 **FileEncryptor GUI (Qt6 / Linux)** 子项目的所有重要变更（图形界面 `FileEncryptorGUI(.exe)`）。
  
命令行子项目的变更记录请见 `../CLI/CHANGELOG.md`，Windows WinUI3 版本见 `../GUI-WinUI/CHANGELOG.md`，
  
自动更新器见 `../Updater/CHANGELOG.md`。

格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

> **GUI 与 CLI 拆分子项目的边界（自 CLI 2.1.0 / GUI 1.0.0 起）**：
>
> - GUI 仅描述本项目自身的实现变更（界面、主题、图标、构建、依赖查找等）。
> - 加密核心 / 算法 / 磁盘格式 v4 / 续传 / YAML 配置 等行为变更请见 `../CLI/CHANGELOG.md`（CLI 是行为实现的承担者）。

## [GUI-Qt 3.0.0] - 2026-10-05

配套 CLI 期望版本 3.0.0。

### Added

- **加密盘图形操作入口**：加密面板新增「入加密盘」勾选与库目录选择（仅当配套 CLI 支持加密盘时显示）；「工具 → 加密盘」提供新建加密盘 / 查看盘内文件 / 修改加密盘密码 / 生成恢复码 / 用恢复码找回密码 / 挂载为磁盘 / 暂时锁定 / 重新解锁共八项入口，菜单项名称采用通俗易懂的措辞；内部维护类动作（重建索引 / 库内重加密 / 删除恢复密钥）不暴露给用户。底层加密盘能力（随机块读、索引、挂载、恢复密钥、可写挂载）由配套 CLI 3.0.0 的 M0–M6 承担，详见 `../CLI/CHANGELOG.md`。
- **挂载为磁盘**：将加密盘挂载为盘符（Linux 下挂载为目录），由后台进程持有；无操作满 1 分钟自动锁定，挂载对话框中已注明此行为。盘符（或目录）默认 `Z:`，并记忆上次所用位置——下次打开对话框即预填，不修改则沿用，修改后生效；加密盘目录也默认落在上次使用的位置。
- **安装包自带 WinFSP 运行时**：`winfsp-x64.dll` 与 `launcher-x64.exe` 随挂载组件一同安装。FE-Mounter 静态依赖该 DLL，缺失时进程将无法启动，表现为「挂载盘不可用」且无任何报错；现于挂载前先做自检，缺失时直接说明原因并提示重新安装。

### Changed

- **检查更新同时显示 GUI 与 CLI 版本号**：「发现新版本」与「已是最新」两种提示都带上当前 GUI 与配套 CLI 的版本号，避免只看 GUI 号对不上实际 CLI。英文 / 俄文界面同步。
- 版本号 2.1.3 → 3.0.0。
- **「入加密盘」可以直接指定已有加密盘**：目标里选一个现成的加密盘目录即可往里加文件；选到空目录会自动将其初始化为新加密盘，目录非空且尚非加密盘时先询问确认，避免将普通文件夹误转为加密盘。
- **任务历史记录「入加密盘」与「打包为一个文件」**：存任务时一并记下这两个选项，从历史恢复任务时自动回填。

### Fixed

- **加密盘锁定后盘符仍能打开**：锁定状态下访问挂载盘（`Z:`）原本返回「设备未就绪」，易被误判为可重试错误而误以为仍可访问。现锁定状态一律返回「拒绝访问」：盘符仍在、可见，但双击无法打开、文件无法读取，真正实现「锁定即拒访」。
- **「入加密盘」选项进加密模式即时可见**：此前要切到别的模式再切回来，「入加密盘」才出现（能力探测与界面默认动作落定时序不一致）。现在加密盘能力探测完成后会重算一次显隐，一进加密模式就能看到该选项。
- **「入加密盘」不再接受盘符**：盘符（`Z:`）只是加密盘的挂载视图，不是数据实际存放的位置，填盘符的输入分支已移除。现仅接受磁盘上的真实存储目录（如 `E:\Disks`）；填写盘符时会明确说明原因与应填内容，而非抛出含义模糊的命令行报错。底层 CLI 同样拒绝盘符根目录，避免将盘符误作普通目录而导致重复加密、污染索引。
- **1 分钟空闲自动锁真的会触发**：此前超时判定按「距上次读写」算，而系统会持续轮询盘里的目录与属性，每次都把计时重置回来，空闲锁永远等不到；同时判定是「有操作才检查」，用户完全不动就永远不检查。现在只有真正的读写 / 新建 / 删除 / 改大小才算「使用」，单纯浏览目录不重置计时；挂载进程另有后台定时器主动上锁，不依赖用户操作。机制说明详见 `../CLI/CHANGELOG.md` 同版本条目。
- **挂载目录 / 盘符被记住**：上次挂载用的加密盘目录与盘符会落盘保存，下次打开挂载对话框已经填好，不用重新翻目录。
- **PQC（后量子）默认勾选确认**：加密模式下 PQC 选项默认勾选；当配套 CLI 支持 `pqc=1` 时保持默认启用，本次一并复核确认。

## [GUI-Qt 2.1.3] - 2026-10-04

配套 CLI 期望版本 2.9.0。本版本的批量任务更快，也更省内存。

### Added

- **新增「包装密钥 / 解开密钥」两个动作**：动作区多了一组单选，跟「生成密钥对」并列，不另起窗口 —— 沿用现有的文件选择区、输出密码和密码框，填入一份 32 字节的密钥文件，选好算法（KWP / AES-KW / 收件人公钥）即可。包装的是密钥而不是文件内容，所以加密模式、压缩、水印、分卷这些加密专属选项会一并收起。配套命令行程序没启用该能力时，这两个单选自动置灰。
- **新增 AES-256-GCM 算法选项**：加密模式与「文件算法」下拉里都能选了。依赖 CPU 的 AES-NI 指令，启动时跟着命令行程序的能力探测自动置灰，不可用时给出明确提示而不是让任务失败。

### Fixed

- **「分卷输出」和「打包为单个容器」两个勾选框外观统一了**：它们和同一排的其它选项用的是系统默认样式，边框、圆角、内边距都跟旁边不一致，看着像另一个控件。现在与「覆盖已存在文件」等同款，分卷大小的单位下拉也一并对齐。
- **密钥包装区块的两个输入框不再长得像外来控件**：密钥文件与输出路径用的还是系统默认样式，边框、圆角、底色都跟同一排的其它输入框不一致。现在与「输出密码」「密钥文件」等同款；水印私钥输入框也一并对齐，之前它同样是漏的。
- **「压缩数据」不再在命令行程序探测偶发失败时永久置灰**：压缩开关原先只在探测成功时才放开，一旦探测进程没能成功完成（被杀软拦截或启动超时），开关就一直点不动。压缩是命令行程序的核心能力、各版本都支持，现在改成「明确声明不支持才禁用」，并补了启动失败兜底，探测偶发失败也不再影响使用。
- **「入加密盘」填挂载盘符能正确落到存储目录**：界面原本把盘符（如 `Z:`）原样传给命令行，新版本命令行已拒绝盘符、会直接报错。现在界面记住每次挂载的「盘符 → 存储目录」映射，填盘符时自动解析回真正的加密盘目录再下发。目录输入框提示改为「加密盘存储目录（如 E:\Disks）；也可填本程序挂载过的盘符（如 Z:）」。
- **挂载后能看到文件、也能直接打开/执行**：依赖共享挂载组件（FE-Mounter）的修复，详见 `../CLI/CHANGELOG.md` 同版本 Fixed 条目。

### Changed

- **配套命令行程序升级到 2.9.0**。
- **批量加解密更快、更省内存**：图形界面的批量任务走的是同一套命令行内核。这版把「密码派生」和「数据加解密」分成两个阶段来调度，不再让十几个线程挤在一起抢派生名额，同时给派生阶段封了并发上限。实测 8 个 64MB 文件的批量加密从 3.4 秒降到 2.5 秒，峰值内存从约 1.5 GB 降到约 523 MB。
- **随附的更新器收紧了传输安全**：内置的自动更新器（Updater）只走 HTTPS（不再接受明文 `http`，杜绝降级绕过），下载跟随 GitHub 的 302 时每一跳都重新核对白名单，Windows 上证书吊销列表因网络环境不可达而握手失败时自动放宽重试一次（证书链与域名校验照旧），并且调用方没给 SHA256 摘要时一律拒绝安装。完整条目见 `../Updater/CHANGELOG.md`。
- **打包开关先探测再下发**：内置 CLI 探测（`--features`）新增 `pack` 项。配套 CLI 不支持 `--pack`（2.8.0 之前）时，界面直接隐藏「打包为单个文件」勾选框并清掉已勾状态，不再把旧 CLI 不认识的 `-p` 发过去导致整个任务被拒。
- **英俄文下选项不再一律竖排**：动作区与选项行此前只看语言判定方向，英文、俄文即便窗口拉得够宽也逐行显示。现在实测整行需要的宽度，放得下就横排；首屏、拉宽窗口、切语言都按真实宽度重新判定（不再一上来就强制竖排）。

## [GUI-Qt 2.1.2] - 2026-10-03

配套 CLI 2.8.0。本版本在每次探测命令行程序时顺手清掉安装目录里版本过低的旧版程序，不至于越攒越多占地方。

### Added

- **分卷大小输入框不再看不清输入的数字**：数字框右侧的增减按钮会压在输入区上，打进去的字符被挡住看不见；同时原先固定挂着「MB」后缀，选 GB / TB 时显示的却还是 MB。现在按钮挪到输入区外侧、加宽输入框，单位只由下拉决定。
- **分卷输出**：选项行新增「分卷输出」，勾上后填分卷大小、单位（MB / GB / TB 任选），密文会切成 `.001`、`.002` 这样的多卷，方便塞进 FAT32、邮件附件或分段上传；解密时随便挑一卷都行，命令行会自己把同组的卷找齐合并。默认不勾，行为和以前一样。
- **自动清理旧版命令行程序**：命令行程序的文件名里带版本号，每装一次新版目录里就多一份，都留着白占地方。现在每次探测到命令行程序时会把目录里版本号低于目标版本的那几份删掉，同版本与更新的版本一律不动，你手动换过的版本也不会被误删。
- **打包为单个容器**：选项行新增「打包为单个容器」，把一整个目录树或一批文件收进单个 `.ptd`，解密时自动展开回原来的目录结构。源文件不动。
- **命令行问「是否继续」时弹窗询问**：命令行遇到「是否覆盖已存在文件」这类询问，以往界面这边没人应答，任务会直接以退出码 1 秒退。现在界面读出命令行具体在问什么，弹窗把选项摆出来，你答完它接着跑。
- **删源目录前先问一句**：输入里有目录、又选了删除 / 安全擦除 / 移入回收站时，运行前会列出待删目录请你确认（超过 5 个折叠成「另有 N 个」）；取消就什么都不做。选「保留源文件」时不会有任何打扰。

### Fixed

- **命令行要答案时不再自己判成拒绝**：密码是通过标准输入喂进去的，写完就把输入通道关了；命令行随后想问你一句是否继续，读到的却是「没有输入」，于是当成你答了「否」并退出。界面与命令行之间现在改走一条独立的应答通道，问答不再受密码通道影响。

### Changed

- **「删源目录」的提示改得和实际动作一致**：实际删的是目录里的文件、目录本身留着（默认输出到源目录时密文就落在目录里，目录也不会空），提示却写成「源目录将被删除」，容易让人以为整棵目录树连根拔起。现在如实说明「源目录中的文件将被……（目录本身保留）」。

## [GUI-Qt 2.1.1] - 2026-10-02

配套 CLI 2.7.1。本版本新增预览解密，主题切换收进「视图」菜单并跟随系统，补齐英文与俄文界面的漏翻文案，修正长文本横排溢出，并收紧中文弱密码判定。

### Added

- **预览解密**：文件列表旁新增「预览...」，选好密文后弹出密码，在新窗口里看到内容前若干字节，不必真的解密出文件；支持「下一个文件」连续查看，字节数可调。
- **主题切换收进「视图」菜单**：原先挤在标题栏右上角的主题下拉与「视图设置」按钮都移进「视图」菜单，主题新增「跟随系统」一档（系统主题变化时自动跟随），与 WinUI 版一致。
- **国庆配色中性化**：各层底色不再铺红系，红只落在强调处，靠明度差与描边分层，红底上的白字更清楚。

### Fixed

- **英文与俄文界面补齐**：任务历史里的动作名（加密 / 解密 / 批量加密 / 批量解密 / 生成密钥对 / 密码派生 / 导出公钥）在两种外语下不再显示中文；后量子 PQC、使用 X448 曲线、签名水印、压缩级别等新加文案补上英文译文。
- **长文本不再横着顶出窗口**：英文 / 俄文模式下动作、密钥管理、选项三行自动改成上下排列并换行显示。
- **「已找到 CLI 程序」换行写法修正**：提示里的换行转义写成了 `/n`，实际会连成一行。
- **中文弱密码不再被放行**：此前只要含非 ASCII 字符就直接判为合格，重复同一汉字的密码也能通过；现在非 ASCII 只算一类字符，全同字符密码一律拒绝。
- **密码强度提示补上英 / 俄译文**：强度等级、字符种类与密码过弱的提示此前没有译入翻译文件，英文界面下显示的是中文。
- **任务完成只弹一次窗**：此前汇总对话框关掉后还会再弹一次消息框。
- **临时文件任务结束即清理**：收件人公钥临时文件与统计 JSON 此前要等到关闭窗口或下次调用才删除。
- **Linux 下自动下载的 CLI 可直接运行**：此前安装时未设执行位，下载完的 CLI 跑不起来（Windows 不受影响）。
- **构建要求的 Qt 版本修正为 6.3**：代码用了 6.3 才有的编码接口，此前声明 6.2，在 6.2 环境会编译失败。

## [GUI-Qt 2.1.0] - 2026-10-02

配套 CLI 2.7.0。本版本把后量子密码、签名水印、SM4-GCM 与 X448 曲线接进界面，新增一键下载 CLI 入口，并修掉了一批选项显示与命令拼装的问题。加密模式、参数顺序与提示文本与 Windows 版保持一致。

### Added

- **后量子开关**：「选项」行新增「后量子 PQC」勾选框，默认开启——非对称收件人改用「X25519 + ML-KEM-768」混合密钥，水印签名改用 ML-DSA-65；取消勾选则回到经典 X25519 / X448 + RSA 路径。当前 CLI 不支持时开关自动置灰。
- **签名水印**：新增「签名水印」勾选框，勾选后出现签名密钥行，可粘贴密钥内容或用「浏览…」读取密钥文件。不填密钥也能加密，只是写入未签名水印记录。
- **水印密钥不在界面上出现**：签名密钥在密码框中输入、不回显明文；命令预览里的密钥参数一律显示为 `<private-key>`；历史记录只存占位符，从历史恢复任务时需重新输入。
- **文件算法下拉**：选中「X25519 非对称」时，模式框右侧出现「文件算法：」下拉（XChaCha20-Poly1305 / AEGIS-256 / SM4-GCM），指定文件本身的加密强度，非对称部分只负责保护会话密钥。
- **SM4-GCM 算法**：加密模式下拉新增「SM4-GCM」。当前 CLI 不支持时该项禁用并回落到 XChaCha20，运行前给出提示。
- **使用 X448 曲线**：新增同名勾选框，勾选后非对称封装与「生成密钥对」改用 X448 曲线；解密时按容器内的收件人条目自动匹配，无需设置。
- **收件人支持 ML-KEM 与 X448 公钥**：收件人框按逗号分隔多个公钥，除 `age1...` 外也识别 `MLKEM1-` 与 `X448-` 开头的串。
- **任务历史记录新增字段**：历史开始保存后量子、水印、水印密钥与文件算法，老记录按默认值读取，从历史恢复任务时一并还原。
- **一键下载 CLI**：「工具 → 下载 CLI...」按当前版本拉取配套 CLI，下载后校验 SHA256 并自动替换，完成后重新探测。
- **Windows 版提供 MSI 安装包**：`GUI-Qt/installer/`（WiX v4 工程）产出 `FileEncryptorGUI-<版本>-Qt-Windows.msi`，主程序与更新器一并装进 `Program Files\FileEncryptor (Qt)`，带开始菜单与桌面快捷方式，升级时自动替换旧版本。Qt 版与 WinUI 版各装各的目录，两个版本可以同时装在机器上互不覆盖；版本号与程序版本同源，改 wixproj 一处即可。MSI 工程已挂进 VS 解决方案（`/GUI-Qt/` 下），右键「生成」即出安装包，无需先手动编一遍 Qt；命令行可用 `powershell -File scripts/build_qt_msi.ps1`。

### Changed

- **选项区重排**：后量子、签名水印、使用 X448 三个勾选项与「强制覆盖」「生成校验单」等同排，不再各占一行。
- **加密模式统一写作「X25519 非对称」**：曲线由「使用 X448」勾选框决定。
- **窗口默认 16:9**：主窗口默认尺寸 1351×759（以宽度为准按 16:9 推算高度）。
- **参数下发顺序固定**：动作 → 输出目录 → 源文件处置 → 加密模式 → 压缩 → 后量子 → 水印 → 校验单 → 收件人 → 输入路径；开关类参数统一排在 `--` 之前，不会被当成文件名。
- **命令预览格式**：选项不加引号，取值一律加引号（含纯数字）。
