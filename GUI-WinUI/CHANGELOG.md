# ChangeLog - FileEncryptor GUI (WinUI 3 / Windows)

本文件记录 **FileEncryptor GUI (WinUI 3)** 子项目的变更。Linux Qt6 版本的变更记录见 [`../GUI-Qt/CHANGELOG.md`](../GUI-Qt/CHANGELOG.md)，CLI 见 [`../CLI/CHANGELOG.md`](../CLI/CHANGELOG.md)。

格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [GUI-WinUI 2.0.2] - 2026-09-27

本版本针对 GUI 侧做一轮安全加固，覆盖口令内存残留、自动下载 CLI 的供应链与路径穿越、子进程资源回收等问题，配套 CLI 期望版本为 2.4.4。

### Fixed
- 写入子进程标准输入的口令字节在使用后立即清零，不再以 `口令 + 换行` 字符串拼接产生额外副本，缩短明文在托管堆的驻留时间。
- 自动下载 CLI 前对保存文件名做基名净化并拒绝路径分隔符，下载链接限定在 GitHub 官方域名白名单内；先落临时文件、存在同名 SHA256 清单时强制校验，通过后再原子移动到应用目录。
- 子进程退出后（含取消路径）统一释放进程对象，避免等待句柄与标准输入句柄在批量任务下累积。
- 与 CLI 交换统计数据的临时文件改用密码学安全随机数命名，放入用户专属目录，并以独占方式打开，消除同名预判与检查-读取之间的竞争窗口。
- 单文件模式下在位置参数前加入 `--` 分隔，避免以连字符开头的文件名被命令行解析器误判为开关。
- 确认口令时同样校验口令强度策略，长度足够但字符种类单一的弱口令不再被直接放行。
- 崩溃日志仅记录异常类型与消息，不再写入异常对象的完整文本与堆栈，降低敏感缓冲内容被落盘的风险。
- 任务完成后对输出目录的递归大小统计改到后台线程执行，避免大目录或网络盘时界面卡顿。
- 多显示器或远程会话等异常配置下，窗口定位不再因工作区为空引用而崩溃。
- 进度文本解析改用安全的整数转换，杜绝未来接入标准输出后遇到异常格式串导致崩溃。
- 自定义背景图仅接受本地文件路径，拒绝远程网络地址，避免应用在用户不知情时发起外联请求。
- 强度指示颜色解析前校验十六进制格式，非法值回退默认色，不再假设固定长度。

## [GUI-WinUI 2.0.1] - 2026-09-27

配套 CLI 2.4.3。本版本完善任务反馈与交互细节，修复 MSI 安装包构建，并统一子窗口视觉风格。

### Added
- **任务完成右下角通知**：批量任务结束时在屏幕右下角弹出 Acrylic 通知，底边滑入、停留后滑出，不抢占焦点。
- **任务历史双击恢复**：双击历史条目可还原当时的命令参数与文件列表勾选状态。

### Changed
- **密码输入框**：改用 PasswordBox 内置的显示密码按钮，选中输入框时可见。
- **子窗口配色**：关于、任务历史等弹窗与主程序深色主题统一，不再出现浅色背景。
- **窗口比例**：默认 16:9。
- **运行/取消按钮**：悬停时在原有绿/红底色基础上加深，不再变灰。
- **产物命名**：框架标识 `-WinUI` 移至平台标识之前，MSI 名为 `FileEncryptorGUI-<版本>-WinUI-Windows.msi`。
- **版本号**：升至 2.0.1，配套 CLI 期望版本 2.4.3。

### Fixed
- **MSI 构建**：修复 WiX v4 项目中 PublishDir 重复定义导致找不到输出文件的问题；安装包支持自定义安装路径、GPLv3 许可证、Windows Terminal 可选 Feature，安装结束页可直接启动 GUI。
## [GUI-WinUI 2.0.0] - 2026-09-26

Windows 侧界面从 Qt6 切换到 WinUI 3（Windows App SDK 1.5 / .NET 8），作为独立项目 `GUI-WinUI/` 存在。Linux 版本保持 Qt6，见 `GUI-Qt/`。

### Added
- **WinUI 3 界面**：布局与 Qt 版保持一致（菜单栏、文件列表、功能区、输出区、状态栏），全部功能无裁剪迁移。
- **文件勾选**：文件列表每项带勾选框，仅勾选的条目参与执行。
- **CLI 未找到提示**：启动时自动探测 CLI，未找到时弹窗列出预期文件名，可重试或前往下载。
- **自定义背景图**：视图设置中可选择图片作为主界面背景，也可随时清除恢复默认。
- **关于对话框**：分为「鸣谢」与「README 摘要」两页。
- **MSI 安装包**：WiX v4 打包，安装到 `%ProgramFiles%\FileEncryptor\`，含开始菜单与桌面快捷方式。
- **VS 解决方案**：根目录 `FileEncryptor.slnx`，VS2026 直接打开。

### Changed
- **背景统一为 Acrylic**：移除 Mica 选项。
- **主题精简**：删除浅色主题与切换选项，默认深色。
- **命令预览**：空闲时显示当前参数，运行时输出首行为完整命令；路径参数自动加引号。
- **加密模式下拉**：默认选中 XChaCha20-Poly1305，非对称项标注为「X25519 + ChaCha20-Poly1305（非对称）」。
- **版本号**：升至 2.0.0，配套 CLI 期望版本 2.4.2。

### Fixed
- 修复任务历史、视图设置等对话框点击无响应的问题。
- 修复「添加目录」报无效窗口句柄的问题。
- 修复 CLI 输出捕获导致界面卡顿的问题，改为直接控制台执行。
- 修复按钮悬停颜色异常，运行按钮绿色、取消按钮红色且悬停加深。

### Technical
- CLI 调用从 `QProcess` 迁移到 `System.Diagnostics.Process`，密钥仍经 stdin 注入。
- 进度帧解析、任务历史、密码强度、ETA 估算等逻辑从 C++ 移植为 C#。
