﻿# ChangeLog - FileEncryptor GUI (WinUI 3 / Windows)

本文件记录 **FileEncryptor GUI (WinUI 3)** 子项目的变更。Linux Qt6 版本的变更记录见 [`../GUI-Qt/CHANGELOG.md`](../GUI-Qt/CHANGELOG.md)，CLI 见 [`../CLI/CHANGELOG.md`](../CLI/CHANGELOG.md)，自动更新器见 [`../Updater/CHANGELOG.md`](../Updater/CHANGELOG.md)。

格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

### 改进
- **独立卸载器工程彻底删除**：3.1.1 里只是停用、不再发布和装入，源码树里还留着整套 WPF 卸载器；现在 `Uninstaller/` 已移除，两套 wixproj 也不再发布它。开始菜单「卸载 FileEncryptor」仍调 `msiexec /x [ProductCode]`，安装包里不再有那 180MB 的 .NET 运行时。
- **依赖目录改名 `third_party` → `Third Party`**：随仓库分发的依赖源码树整体换了目录名，CMake preset、依赖查找、安装包路径、Linux 构建脚本和文档里的引用一并改过。新目录名带空格，CMake 的 `add_subdirectory` 与头文件路径、README 里的命令行示例都补了引号；上游源码与历史变更记录里的旧路径按原样保留。
- **一键构建补齐并实跑**：Windows 侧从 CLI、FE-Mounter 到两套 MSI 的六步矩阵，现在可由 `scripts/build_all.py --win` 一次跑完并把产物收进发布目录。构建用的辅助脚本放在 `scripts/` 下，按仓库约定不入库，换机需自备。CMake 参数改走初始缓存文件，避免批处理把 `-DKEY=VAL` 的等号拆开；工具链自行补 Windows SDK 路径、规范化代理环境变量，不再依赖注册表查询。
- 程序集版本 `AssemblyVersion` / `FileVersion` 与对外版本对齐为 `3.1.1.0`；同版本覆盖安装仍由 installer 的 `AllowSameVersionUpgrades` 保证先卸后装。

## [GUI-WinUI 3.1.1] - 2026-10-22

配套 CLI 期望版本 3.1.1（与 FE-Mounter 3.1.1 协同）。

### 修复
- **加密盘「格式化」失败却把索引清空，盘内文件「全丢」（2026-10-23）**：盘正被挂载时 CLI 删不掉 `.ptd`，旧逻辑删失败只打 `Warning: cannot remove …` 后照样把索引写成空——索引空、文件还在，用户视角就是「格式化失败后文件全没了」。现 CLI 只要还有一个 `.ptd` 删不掉就立即报错返回、**完全不动索引**，并提示先卸载该盘；GUI 侧错误输出照原样呈现，配「重建索引...」即可从盘面文件头找回条目。
- **文件列表勾选框「不起作用」（2026-10-23）**：勾选/取消其实一直影响命令行，但勾选态变化不触发命令预览刷新，界面毫无反馈，看起来就像没生效。现勾选态变更即时刷新「命令预览」，所见即所得。
- **文件列表「预览」按钮必报文件不存在（2026-10-23）**：「预览」取 `FileList.SelectedItem` 后按 `string` 转型，而该项实际是 `SelectablePath` 对象，转型恒空再 `ToString()` 得到的是类型名，于是永远报「文件不存在」。现改为取 `.Path`。
- **批量加密只输一次密码（2026-10-23）**：批量加密（入新加密盘）不弹确认框，弱口令打错也无法察觉。现与普通加密口径一致：入**新建**加密盘 / 密钥派生 / 包装密钥要求二次确认；入**已初始化**加密盘（既有密码）仍只输一次，避免旧口令被现行强度策略拒之门外。
- **覆盖安装后程序还是旧版（2026-10-23，打包链）**：Windows Installer 对「已装文件版本 ≥ 新文件」直接跳过复制，而本产品每个构建的 exe/dll 版本号都相同（3.1.1.0），于是覆盖安装常出现「安装成功但功能没变」甚至「新 XAML + 旧 DLL」启动即崩。现 MSI 里为主程序集 / 主 exe / CLI / FE-Mounter / vdisk.dll / Updater 各加 `RemoveFile On="install"`：安装时先删同名旧二进制再复制，彻底绕开版本比较规则。
- **MSI 装入旧 XAML / 旧资源表（2026-10-23）**：wixproj 原从 `win-x64\` 子目录拷 `.xbf`（RID 构建的陈旧中间产物），且从不刷新 `resources.pri`；新 DLL + 旧 XBF 的元素编号错位会让启动直接抛 `InvalidCastException`。现 `.xbf` 改从普通 Build 顶层输出拷，并显式同步 `resources.pri`。
- **普通加密只输一次密码**：此前普通文件加密也会弹出「密码 + 确认密码」两框。现仅「新建加密盘」（设置新密码）才要求二次确认，普通加密 / 解密 / 解包 / 已初始化加密盘（填既有密码）均只输一次。（Qt 前端同步修复：此前 Qt 端加密一律带确认框，现同样仅「入新加密盘」才二次确认。）
- **预览解密（记事本）读取文件报错**：预览走 CLI `--preview` 却漏传 `--key-stdin`，密码从未经 stdin 送达 CLI，导致解密失败、预览窗报「预览失败」。现已补上 `--key-stdin`，预览恢复正常。
- **「重新解锁」等控制面弹窗末尾的生硬 "OK"**：IPC 成功响应常为裸 `"OK"`，原样弹在消息框里。现统一替换为人话「操作成功完成。」（其他相同文案一并修正）。

### 新增
- **「加密盘 → 重建索引...」（2026-10-23）**：选盘 → 警告确认 → 输盘密码，扫描盘内全部 `.ptd`，从文件头恢复原名 / 大小 / 算法重建分片索引，用于找回「索引写入失败、索引与盘面不一致」而看不见的文件；已登记条目不受影响。盘正在挂载时会提示先卸载。中 / 英 / 俄三语文案齐备。
- **「暂时不锁定」**：「加密盘 → 暂时不锁定」菜单（与「暂时锁定」同列表）——选择暂停时长（2/5/10/15/30/60 分钟或自定义 1–1440 分钟）、两次确认后，该时段内不自动锁（到期自动恢复，期间仍可由「锁定」手动上锁）。**修复此前「设了仍被锁」**：暂停原只挡住挂载层 watchdog，库层空闲计时未同步关闭，库仍会在 I/O 路径到点自行上锁；现 suspend 时一并关闭库侧计时，取消暂停 / 手动上锁 / 重新解锁 / 暂停到期时按当前窗口恢复，到期另给一个完整过渡窗口而非当场上锁。**接入 DPAPI**：已开「本机免密」的盘无需重复输密码；未开的盘确认后顺带经 DPAPI 绑定（本机免密），暂停期间若仍被锁将自动用本机凭据恢复解锁。

### 改进
- **删除「加密盘管理」页，「本机免密」开关移至挂载时勾选**：菜单「加密盘 → 加密盘管理...」及其对话框整体移除（该页此前的滚动条显示问题随之不存在）。原本机免密（DPAPI 设备绑定）开关改到「挂载为磁盘」对话框：勾选后挂载成功即把库密码经 DPAPI 存于本机，今后在本机解锁此盘不再输密码；取消勾选则删除已存凭据，回到每次输密码。已绑定过的盘在挂载对话框默认勾上。
- **卸载改用 Windows Installer 标准界面，安装包同步瘦身**：开始菜单「卸载 FileEncryptor」原指向随包发布的独立 WPF 卸载程序（自包含单文件实测约 180MB，体积几乎全是 .NET 运行时，且还要用户多点一次按钮）。现改为直接调 `msiexec /x [ProductCode]`——用户看到的是熟悉的 Windows Installer 维护/卸载界面，安装包也不再捆绑该 180MB 文件（`Uninstaller` 工程停用，不再发布/装入）。同时补上此前的两处残留短板：① `util:CloseApplication` 由「只发关闭消息」升级为「关闭消息 + 3 秒超时强杀（TerminateProcess）」，并覆盖安装目录内全部 exe（GUI / FE-Mounter / CLI / Updater / RestartAgent）——漏杀一个进程就会锁住文件使卸载残留；② 新增 `CleanInstallDir` 自定义操作：真实卸载（非大版本升级现场）在 RemoveFiles 后强制清除安装目录，运行时产物（如 GUI 更新暂存目录 `update_staging`）与空目录不再留在 Program Files。
- **「电影和电视」等播放器读加密盘时被自动锁（2026-10-22）**：文件读一次即进系统缓存，后续读取不再产生磁盘 I/O，自动锁计时无从续期——看片看到一半盘被锁。现挂载层在「前台进程仍持开文件句柄」时持续续期两层计时（播放器读缓存命中后不发 I/O，但人还在看）；同时前台窗口判定对控制台程序自己的窗口（`PseudoConsoleWindow`）网开一面。**根因另有一处隐藏故障**：库层新增的三个忙闲/锁态 ABI（`vdisk_note_activity` / `vdisk_index_stamp` / `vdisk_is_unlocked`）此前定义误落在 C++ 匿名 namespace 内，导出成修饰名，挂载层按名 `GetProcAddress` 全部加载失败，「持开文件续期」从未真正生效——现定义移至全局作用域，导出为纯 C 名字，加载侧并补缺失告警。
- **「暂时不锁定」设了无效（2026-10-22）**：两个根因——① CLI `ipc-call suspend <minutes>` 客户端漏传分钟数，服务端按 0 处理走「取消暂停」分支，设了瞬间被取消；② 挂载层 watchdog 用 `idle_remaining()==UINT32_MAX` 判「库已自行锁定」，与 suspend 的「超时关 0」语义撞车，暂停期间每秒误判已锁。现客户端补传参数，库层新增 `vdisk_is_unlocked` 直查真实锁态，暂停语义完全恢复（冒烟测试 5 项全过）。
- 版本号随 CLI 同步升至 3.1.1。

### 安全 / 性能（共享挂载组件 FE-Mounter 3.1.1）
- **新增 IPC `suspend <minutes>`**：暂停自动锁的底层能力，配合 GUI「暂不锁」使用；`vaults status` 现回报 `suspend` 剩余秒数字段。

## [GUI-WinUI 3.0.1] - 2026-10-06

### 新增
- **「工具 → 加密盘」新增「卸载磁盘」与「格式化加密盘」**（与 Qt 前端同源，现共十项入口）：卸载走挂载组件的 `ipc-call eject`，由持有盘符的后台进程停服务退出后释放盘符，不强杀进程（避免跳过索引落盘等收尾）；格式化调用 CLI `--vault-format` 清空盘内全部文件，执行前有不可撤销确认并要求输入盘密码，盘身份与密码保留。
- 挂载盘在资源管理器中的卷标改为「加密磁盘」（此前误按字符数填写长度，中文标签被截成半个字）；属性页「文件系统」一行恢复为产品标识 `FE-Vault`；「容量」按盘内实际内容大小显示（含 `.feindex` 与 `vault.meta` 占用），不再显示空闲余量。

### 修复
- **挂载后看不到新入盘的文件**：挂载进程持有的索引不再与磁盘同步，现在会随 `.feindex` 变化自动重载，GUI 往盘里加密文件后无需重新挂载即可看到。
- **命令行窗口进度刷出多余新行**：帧渲染留出 1 列余量避免终端自动换行导致光标错位，入盘过程中的告警改为帧结束后统一输出。
- **主任务「■取消」失效**：系统控制台模式下此前经 `cmd.exe /c fe_run_xxx.cmd` 间接启动 CLI，`Cancel()` 的 `Kill` 只能杀掉 `cmd.exe`、杀不掉其后的 CLI 子进程，表现为点取消后任务仍在后台跑、进度纹丝不动。现改为直接以 CLI 路径启动并传 UTF-16 精确参数（同时消除临时 `.cmd` 的 OEM 代码页中文乱码），`Cancel()` 可即时终止 CLI。
- **空闲自动锁长时间不触发**：挂载参数 `PostCleanupWhenModifiedOnly=1` 会让 WinFsp 只为「被修改/删除」的文件投递 `Cleanup` 回调，纯浏览、读取这类未修改的打开收不到回调，导致占用句柄计数只增不减、空闲超时永不满足（表现为开着盘不用，几分钟甚至更久都不自动锁）。现关闭该项优化使 `Cleanup` 必定投递；同时目录句柄不再计入占用（资源管理器文件夹视图会长期持有目录变更通知句柄），并在句柄被长期持有时增加一倍超时宽限，保证最坏 2 分钟必定锁定。附带修复每次只读打开泄漏的 `FeCtx`。
- **入加密盘结束后 GUI 统计全为 0**：入盘路径此前从不写 `FILEENCRYPTOR_STATS_FILE` 统计 JSON（该写入只在批量加/解密 `process_files` 里），导致 GUI 退出时读到空文件、完成面板 `完成/跳过/失败/共` 全部显示 0。现已在入盘收尾补写同样格式的统计（含 `files_done/files_failed/files_skipped/total_files/total_bytes`），GUI 末态统计准确。
- **入加密盘目录树丢失（跨盘源）**：入盘 rel_path 此前对外部/跨盘源用 `std::filesystem::relative` 做规范化，跨盘时返回带 `..` 前缀或被判定异常后回退成纯文件名，整棵目录树被拍平（如 `D:\temp\aaa\x.txt` 落盘成 `x.txt`）。现改用 `lexically_relative` 并显式保留盘符作顶层目录：外部源 `D:\temp\aaa\x.txt` 入盘后 rel_path 为 `D/temp/aaa/x.txt`，挂载盘里即 `Z:\D\temp\aaa\x.txt`，多层与中文子目录均正确保留。

### 改进
- **窗口标题构建时间戳（诊断用，已撤销）**：曾临时在标题附构建时间（形如 `FileEncryptorGUI 3.0.1 · 10-11 08:30`）用于排查「同版本覆盖安装不替换文件导致跑旧构建」的问题；部署链路确认无误后已移除，标题恢复为纯版本号。
- 配合 CLI 3.0.1：勾选「入加密盘」加密时，命令行窗口按并行核心数显示多条进度（帧式输出每线程一行）。
- 版本号随 CLI 同步升至 3.0.1。
- 配合 CLI / 共享挂载组件 FE-Mounter 3.0.1 热修：挂载盘默认开启预读缓存（文件较多的加密盘在资源管理器里滑动不再逐帧卡顿）；空闲自动锁改为仅在「无程序占用且达 1 分钟上限」时触发；入盘若仅个别文件失败、其余成功，不再误报「程序执行失败」。

### 安全 / 性能（共享挂载组件 FE-Mounter）
- **挂载盘枚举大幅提速**：底层 `vdisk.dll` 新增派生索引缓存（路径 → 下标 O(1)、父目录 → 子项 O(子项数)、目录集合 O(1)、容量统计 O(1)），并把 `.feindex` 变更检测从每次调用改为 200ms 轮询节流。挂载含数千加密文件的加密盘时，资源管理器滑动列表不再卡成 PPT（基准实测枚举约 23× 提速）。
- **修复挂载进程目录缓冲区栈溢出（高危）**：`wf_ReadDirectory` 的固定 512-WCHAR 栈缓冲此前按实际文件名字节数填写大小，超长文件名会越界写穿栈帧；已加超长名跳过守卫。
- **加固加密盘索引路径穿越（中危）**：索引解析拒绝绝对路径 / 盘符 / `.` / `..` 组件，`.ptd` 落盘路径对 `..` 直接拒绝，防止伪造索引条目把密文写到库外。
- **挂载盘支持重命名 / 移动**：此前挂载的加密盘改名报「MSDOS 功能无效」（挂载层无 Rename 回调），现底层 `vdisk.dll` 与 FE-Mounter 均已补齐——文件改名、目录改名（含递归子项批量改索引路径并搬运各自的 `.ptd`）可用；目标已存在返回冲突而非覆盖。**热修（2026-10-21）**：WinFSP 驱动对 Rename 的 `FileName` 与移动目标父目录段做大写归一化，而索引存原始大小写，导致改名 / 移动一律报「找不到项目」、移入子目录时目录大小写分裂、异形大小写路径无法打开。`vdisk.dll` 已修复（查找键统一大小写不敏感、`.ptd` 路径按索引原始大小写拼接、目录 readdir 幽灵自嵌套），需随新版 `vdisk.dll` 一并更新。
- **挂载盘里拷入 / 新建文件夹也保留目录树**：此前挂载层把目录当成 0 字节文件写索引，导致整层文件夹在资源管理器里「消失」、无法进入。现索引条目加 `is_dir` 一等公民，挂载层改走目录感知的创建接口——`mkdir` / 往盘里拖文件夹只登记目录条目（不建无意义的 `.ptd`），列目录 / 查属性 / 判定目录全部认这个标志。
- **「入加密盘」索引写入去掉 O(N²) 重加密**：批量入盘每追加一条就整体重加密整份索引（2100 文件约 5+ 分钟），现改为 O(1) 摊销追加 + 末尾一次性落盘，入盘总时长随文件数线性增长。

## [GUI-WinUI 3.0.0] - 2026-10-05

配套 CLI 期望版本 3.0.0。

### Added

- **加密盘图形操作入口**：加密面板新增「入加密盘」勾选与库目录浏览（能力不可用时整行隐藏并清空残留路径）；「工具 → 加密盘」提供新建加密盘 / 查看盘内文件 / 修改加密盘密码 / 生成恢复码 / 用恢复码找回密码 / 挂载为磁盘 / 暂时锁定 / 重新解锁共八项入口，菜单项名称采用通俗易懂的措辞；内部维护类动作（重建索引 / 库内重加密 / 删除恢复密钥）不暴露给用户。底层能力由配套 CLI 3.0.0 的 M0–M6 承担，详见 `../CLI/CHANGELOG.md`。

- **选项区改为横向勾选框排列**：后量子、使用 X448、签名水印与「覆盖已存在文件」「生成校验单」同排，签名私钥独立成行，勾选后才出现。
- **加密模式统一写作「X25519 非对称」**：曲线由「使用 X448」勾选框决定。
- **动作与密钥管理互斥**：选中其中一组会自动清掉另一组的勾选，不会出现两个动作同时点亮。
- **参数下发顺序与命令预览格式**与 Qt 版一致，私钥参数一律遮蔽。
- **版本号升到 2.1.0**（配套 CLI 2.7.0）：程序集版本、推荐下载的 CLI 文件名与下载标签一并跟随。

### Fixed

- **命令预览不再显示私钥明文**：勾选签名水印并填入密钥（或「浏览…」读进来）后，预览与输出日志里原本跟着私钥正文，现在一律只显示 `<private-key>`。
- **窗口启动即退出**：勾选框初值改在代码里设置，XAML 不再写 `IsChecked`，避免解析 XAML 时失败；崩溃时的异常与调用栈写入 `crash.log`，下次启动可直接查看。
- **密钥管理三项下不再显示加密专属字段**：选「生成密钥对 / 密码派生 / 导出公钥」时隐藏加密模式、压缩、源文件处置、生成校验单与签名水印，并清掉对应勾选，CLI 不会收到对当前动作无意义的开关。
- **解密与批量解密下不再残留「加密模式」与「压缩」行**：两处改为整行收起（含标签与级别输入）。
- **非对称模式不再误用 SM4 参数**：此前模式索引错位，选到非对称却下发 `-m sm4`。
- **非对称模式现在也能压缩**：CLI 本就支持非对称压缩，此前界面把非对称排除在外。
- **构建前请保持工程目录干净**：工程目录下如果残留 `MainWindow.xaml` 一类的副本会被一并编译，构建前顺手清掉即可。
- **更新器起不来不再一直转圈**：检查请求 60 秒、下载 5 分钟未返回结果就中止更新器进程并提示；更新器进程本身起不来时立刻提示，不会干等它结束。
- **检查失败能看出原因**：网络不通、DNS 解析失败、连接超时、TLS 证书、GitHub 限流、找不到对应 release、下载域名未放行等情况各有对应说明，并附更新器返回的原始信息。
- **英文 / 俄文界面不再漏翻**：「后量子 PQC」「使用 X448」「签名水印」「水印签名密钥」及其提示、压缩级别标签此前仍显示中文，补齐中 / 英 / 俄词条后三语一致。
- **悬停提示跟着语言切换**：后量子、使用 X448、签名水印、文件算法的悬停说明此前不参与翻译，切换语言后照旧显示中文。
- **英文 / 俄文下文字不再被裁掉**：「动作」「密钥管理」「选项」三行控件在英文与俄文下比中文长得多，横排会超出卡片宽度；非中文界面改为逐行排列，文字完整可见，中文保持一行排开。
- **下载按文件大小校验**：从更新结果里取到的文件大小会一并传给更新器，落盘后比对，缺失 SHA256 时也不会把错误页当安装包。
- **MSI 的版本号跟着程序走**：安装包此前固定标成 2.0.1，和程序的 2.1.0 对不上。现在版本号只在 `installer/FileEncryptorGUI.Installer.wixproj` 里写一次，MSI 的版本号与安装文件名会一起跟着变。
- **更新器随安装包一起装进程序目录**：安装包里带上 Updater.exe，装完就能直接用「检查更新」，不用另外去拷一个更新器文件。

### Changed

- **安装包各装各的目录**：Qt 版装到 `FileEncryptor (Qt)`，WinUI 版装到 `FileEncryptor (WinUI)`，两个版本可以同时装在机器上互不覆盖；开始菜单按目录分开，桌面快捷方式各自带框架标注。
- **参数逐项传递与超时兜底**：调用更新器时参数按列表逐项下发，更新器起不来、没有输出或超时都会被捕获并提示，不会静默无反应。
