# ChangeLog - FileEncryptor GUI (WinUI 3 / Windows)

本文件记录 **FileEncryptor GUI (WinUI 3)** 子项目的变更。Linux Qt6 版本的变更记录见 [`../GUI-Qt/CHANGELOG.md`](../GUI-Qt/CHANGELOG.md)，CLI 见 [`../CLI/CHANGELOG.md`](../CLI/CHANGELOG.md)，自动更新器见 [`../Updater/CHANGELOG.md`](../Updater/CHANGELOG.md)。

格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [GUI-WinUI 2.1.0] - 2026-10-02

配套 CLI 期望版本 2.7.0。本版本把后量子密码、签名水印、SM4-GCM 与 X448 曲线接进界面，修正了一批选项显示、命令预览与布局问题，界面与 Qt 版保持一致，版本号一并升到 2.1.0。

### Added

- **后量子开关**：「选项」行新增「后量子 PQC」勾选框，默认开启——非对称收件人改用「X25519 + ML-KEM-768」混合密钥，水印签名改用 ML-DSA-65；取消勾选则回到经典 X25519 / X448 + RSA 路径。当前 CLI 不支持时开关自动置灰。
- **签名水印**：新增「签名水印」勾选框，勾选后出现签名密钥行（密码框 + 浏览按钮），可粘贴密钥内容或读取密钥文件。不填密钥也能加密，只是写入未签名水印记录。
- **水印密钥不在界面上出现**：签名密钥在密码框中输入、不回显明文；命令预览里的密钥参数一律显示为 `<private-key>`，历史记录只存占位符，从历史恢复任务时需重新输入。
- **文件算法下拉**：选中「X25519 非对称」时，模式框右侧出现「文件算法：」下拉（XChaCha20-Poly1305 / AEGIS-256 / SM4-GCM），指定文件本身的加密强度，非对称部分只负责保护会话密钥。
- **SM4-GCM 算法**：加密模式下拉新增「SM4-GCM」。
- **使用 X448 曲线**：新增同名勾选框，勾选后非对称封装与「生成密钥对」改用 X448 曲线；解密时按容器内的收件人条目自动匹配，无需设置。
- **任务历史记录新增字段**：历史开始保存后量子、水印、水印密钥与文件算法，老记录按默认值读取，从历史恢复任务时一并还原。
- **下载 CLI 入口**：「CLI 未找到」对话框与工具菜单均可按当前版本拉取配套 CLI，下载后校验 SHA256 并自动替换，完成后重新探测。

### Changed

- **选项区改为横向勾选框排列**：后量子、使用 X448、签名水印与「覆盖已存在文件」「生成校验单」同排，签名私钥独立成行，勾选后才出现。
- **加密模式统一写作「X25519 非对称」**：曲线由「使用 X448」勾选框决定。
- **动作与密钥管理互斥**：选中其中一组会自动清掉另一组的勾选，不会出现两个动作同时点亮。
- **参数下发顺序与命令预览格式**与 Qt 版一致，私钥参数一律遮蔽。
- **版本号升到 2.1.0**（配套 CLI 2.7.0）：程序集版本、推荐下载的 CLI 文件名与下载标签一并跟随。

### Fixed

- **命令预览不再显示私钥明文**：勾选签名水印并填入密钥（或「浏览…」读进来）后，预览与输出日志里原本跟着私钥正文，现在一律只显示 `<private-key>`。
- **窗口启动即退出**：勾选框初值改在代码里设置，XAML 不再写 `IsChecked`，避免解析 XAML 时失败；崩溃时的异常与调用栈写入 `crash.log`，下次启动可直接查看。
- **密钥管理三项下不再显示加密专属字段**：选「生成密钥对 / 口令派生 / 导出公钥」时隐藏加密模式、压缩、源文件处置、生成校验单与签名水印，并清掉对应勾选，CLI 不会收到对当前动作无意义的开关。
- **解密与批量解密下不再残留「加密模式」与「压缩」行**：两处改为整行收起（含标签与级别输入）。
- **非对称模式不再误用 SM4 参数**：此前模式索引错位，选到非对称却下发 `-m sm4`。
- **非对称模式现在也能压缩**：CLI 本就支持非对称压缩，此前界面把非对称排除在外。
- **构建前请保持工程目录干净**：工程目录下如果残留 `MainWindow.xaml` 一类的副本会被一并编译，构建前顺手清掉即可。
- **更新器起不来不再一直转圈**：检查请求 60 秒、下载 5 分钟未返回结果就中止更新器进程并提示；更新器进程本身起不来时立刻提示，不会干等它结束。
- **检查失败能看出原因**：网络不通、DNS 解析失败、连接超时、TLS 证书、GitHub 限流、找不到对应 release、下载域名未放行等情况各有对应说明，并附更新器返回的原始信息。
- **下载按文件大小校验**：从更新结果里取到的文件大小会一并传给更新器，落盘后比对，缺失 SHA256 时也不会把错误页当安装包。
- **MSI 的版本号跟着程序走**：安装包此前固定标成 2.0.1，和程序的 2.1.0 对不上。现在版本号只在 `installer/FileEncryptorGUI.Installer.wixproj` 里写一次，MSI 的版本号与安装文件名会一起跟着变。
- **更新器随安装包一起装进程序目录**：安装包里带上 Updater.exe，装完就能直接用「检查更新」，不用另外去拷一个更新器文件。

### Changed

- **安装包各装各的目录**：Qt 版装到 `FileEncryptor (Qt)`，WinUI 版装到 `FileEncryptor (WinUI)`，两个版本可以同时装在机器上互不覆盖；开始菜单按目录分开，桌面快捷方式各自带框架标注。
- **参数逐项传递与超时兜底**：调用更新器时参数按列表逐项下发，更新器起不来、没有输出或超时都会被捕获并提示，不会静默无反应。
