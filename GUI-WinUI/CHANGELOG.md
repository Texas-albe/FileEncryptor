# ChangeLog - FileEncryptor GUI (WinUI 3 / Windows)

本文件记录 **FileEncryptor GUI (WinUI 3)** 子项目的变更。Linux Qt6 版本的变更记录见 [`../GUI-Qt/CHANGELOG.md`](../GUI-Qt/CHANGELOG.md)，CLI 见 [`../CLI/CHANGELOG.md`](../CLI/CHANGELOG.md)，自动更新器见 [`../Updater/CHANGELOG.md`](../Updater/CHANGELOG.md)。

格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased] - 2026-10-01

### Changed
- **下载域名白名单与 Updater 同步**：`IsAllowedDownloadHost` 改为四主机精确匹配（与 `Updater/src/updater.cpp` 的 `kGitHubHosts` 一致，大小写不敏感，`new Uri` 解析失败即拒绝），不再放行借用 GitHub 子域的地址。Updater / GUI-Qt / GUI-WinUI 三处白清单一，互不漂移。

## [GUI-WinUI 2.0.3] - 2026-09-30

配套 CLI 期望版本 2.4.5。本版本集成自动更新器与多语言框架，新增节日窗口限定配色，并按桌面惯例重排菜单栏。

### Added
- **自动更新器（集成 Updates/009）**：「关于」菜单新增「检查更新...」项，调用 `Updater` 工具查询 GitHub Releases 最新版本（按 GUI 框架/平台匹配资产：WinUI/Windows → `*WinUI*Windows*.msi`），支持下载并以 SHA256 校验后安装；常驻进度对话框实时回写进度。实现为静态链接 bundled libcurl（Windows Schannel TLS）+ 内置纯 C++ SHA-256 与最小 JSON 解析，零外部动态库依赖（详见 `../Updater/CHANGELOG.md`）。
- **多语言（集成 Updates/007 i18n，zh-CN / en-US）**：新增内嵌字典 `Services/L10n` 服务（约 130 条英文译文，键即中文源文，缺失回退中文）；XAML 静态文本经视觉树遍历替换，代码内消息统一经 `L10n.T / L10n.F`；首次启动跟随系统 UI 语言。
- **「工具 → 语言 / Language」子菜单**：简体中文（默认）/ English；切换保存设置并提示「立即重启 / 稍后」，重启后全局一致生效。
- **标题栏版本号动态化**：修复标题与「鸣谢 / README 摘要」面板硬编码 `2.0.0`，改由 `FileEncryptorLocator.GuiVersion` 生成。
- **节日窗口限定配色（每年 10/1–10/7 自动启用）**：节日窗口内覆盖系统主题色——强调色、窗口 / 卡片 / 控件底色与文字色统一换成中国国旗红（`#DE2910` 系），主操作按钮同步走红系（含 hover / pressed 态），非节日窗口无任何影响。仅覆盖主色调，口令强度、警告值等语义色保持原样，避免信息误读。启动期判定，跨天需重启（`Services/NationalDayTheme.cs`）。
- **系统控制台执行 CLI**：CLI 改在独立的系统控制台窗口中运行（`cmd.exe` 包装，窗口标题 `FileEncryptor CLI`），进度、结果与提示都在控制台内；任务结束后窗口保留 3 秒再关闭，退出码经延迟展开（`!errorlevel!`）回传，避免被 `timeout` 覆盖成 0。
- **控制台模式下口令仍由 GUI 传入**：运行前先按 `NeedsPassword()` 判断（非对称、已指定密钥文件、非口令类动作均无需口令），需要则弹密码框，口令经 stdin 管道注入子进程，不再由 CLI 自行交互提示。

### Changed
- **菜单栏按桌面应用常见顺序重排**：关于→编辑→工具→视图 调整为 编辑→视图→工具→关于（功能类在前、信息类最后）。
- **配套 CLI 版本追踪 2.4.4 → 2.4.5**：`FileEncryptorLocator.ExpectedCliVersion` 与下载 tag（`GUI2.0.3_CLI2.4.5`）随 CLI 更新。
- **主界面布局调整**：文件选择区与右侧操作区宽度比改为 1:2（原为固定 560px + 剩余），匀出的空间给操作选项；移除底部输出区，CLI 输出改由系统控制台承载。
- **语言切换即时生效**：切换语言后立即重建全界面译文（含折叠面板与下拉项），不再提示「立即重启 / 稍后」。
- **俄文（Русский）界面翻译**：`Services/L10n` 新增 `Ru` 常量与 `RuMap`（185 条，键即中文源文，缺失回退中文），并重写 `T()` 以「中文基准 → 目标语言」规范化，支持 zh/en/ru 任意顺序切换（含英文 / 俄文界面切回中文时正确还原源文）；「关于 → 语言 / Language」子菜单新增 `Русский` 单选，即时刷新生效。

### Fixed
- **「下载 CLI」按钮无反馈**：原实现在 CLI 未找到对话框关闭后才更新其内部的进度控件，用户点完按钮看不到任何反馈、误以为失效。改为弹出独立的「下载 CLI」对话框（自带常驻进度条与状态文本，下载过程实时回写），并对发布版本检索增加 `_CLI` 后缀兜底，确保可靠定位 CLI 资产。
- **下载 CLI 兜底取最高版本**：原逻辑先取同名 GUI 下最高的 CLI 版本、找不到再取任意 `_CLI` 的最高版本，会下到与预期版本不一致的包。改为只认精确配套的 `GUI<GUI版本>_CLI<CLI版本>` tag，未找到返回 -1 并提示要求的具体 tag 后中止，不再兜底。
- **英文界面残留中文**：「CLI 未找到」弹窗正文、`压缩级别（0-22）` 等多处漏译已补齐；右侧选项标签列由 80px 加宽至 120px 并允许按单词折行，`Encryption mode` 不再被截断，中文标签也不再按字符乱折。
- **英文配置下重启出现中英混杂**：本地化遍历由视觉树改为逻辑树下钻——构造期视觉树尚未建立，且 `Visibility=Collapsed` 的面板与未展开的下拉项都不在视觉树中，这些元素此前永远拿不到译文。
- **向 stdin 追加多余换行**：WinUI 曾在口令字节后追加 `0x0A`，而 CLI 不裁剪 stdin 口令的尾部换行，导致其加密出的文件无法用 CLI 交互输入或 Qt 版解密。现与 Qt 一致，原样发送口令字节。
- **WinUI 口令策略最小长度与 Qt 对齐**：`PasswordStrengthService.MinPasswordLength` 由 6 改为 8，与 Qt `PasswordStrength::kMinPasswordLength` 一致；熵计算改用 `MidpointRounding.AwayFromZero` 对齐 `std::round`，其余阈值（弱/中/强分级、字符类别与长度门槛）本就一致。

## [GUI-WinUI 2.0.2] - 2026-09-27

配套 CLI 期望版本 2.4.4。本版本针对 GUI 侧做一轮安全加固，覆盖口令内存残留、自动下载 CLI 的供应链与路径穿越、子进程资源回收等问题。

### Fixed
- **口令 stdin 字节用后即清**：写入子进程标准输入的口令字节在使用后立即清零，不再以 `口令 + 换行` 字符串拼接产生额外副本，缩短明文在托管堆的驻留时间。
- **自动下载 CLI 供应链加固**：下载前对保存文件名做基名净化并拒绝路径分隔符，下载链接限定在 GitHub 官方域名白名单内；先落临时文件、存在同名 SHA256 清单时强制校验，通过后再原子移动到应用目录。
- **子进程对象统一释放**：子进程退出后（含取消路径）统一释放进程对象，避免等待句柄与标准输入句柄在批量任务下累积。
- **统计临时文件安全命名**：与 CLI 交换统计数据的临时文件改用密码学安全随机数命名，放入用户专属目录，并以独占方式打开，消除同名预判与检查-读取之间的竞争窗口。
- **位置参数 `--` 分隔**：单文件模式下在位置参数前加入 `--` 分隔，避免以连字符开头的文件名被命令行解析器误判为开关。
- **确认口令同校验强度**：确认口令时同样校验口令强度策略，长度足够但字符种类单一的弱口令不再被直接放行。
- **崩溃日志最小化**：崩溃日志仅记录异常类型与消息，不再写入异常对象的完整文本与堆栈，降低敏感缓冲内容被落盘的风险。
- **输出目录统计后台化**：任务完成后对输出目录的递归大小统计改到后台线程执行，避免大目录或网络盘时界面卡顿。
- **多显示器窗口定位兜底**：多显示器或远程会话等异常配置下，窗口定位不再因工作区为空引用而崩溃。
- **进度文本安全解析**：进度文本解析改用安全的整数转换，杜绝未来接入标准输出后遇到异常格式串导致崩溃。
- **背景图仅接受本地路径**：自定义背景图仅接受本地文件路径，拒绝远程网络地址，避免应用在用户不知情时发起外联请求。
- **强度指示颜色校验**：强度指示颜色解析前校验十六进制格式，非法值回退默认色，不再假设固定长度。

## [GUI-WinUI 2.0.1] - 2026-09-27

配套 CLI 2.4.3。本版本完善任务反馈与交互细节，修复 MSI 安装包构建，并统一子窗口视觉风格。

### Added
- **任务完成右下角通知**：批量任务结束时在屏幕右下角弹出 Acrylic 通知，底边滑入、停留后滑出，不抢占焦点。
- **任务历史双击恢复**：双击历史条目可还原当时的命令参数与文件列表勾选状态。

### Changed
- **密码输入框**：改用 PasswordBox 内置的显示密码按钮，选中输入框时可见。
- **子窗口配色**：关于、任务历史等弹窗与主程序深色主题统一，不再出现浅色背景。
- **窗口比例**：默认 16:9。
- **运行/取消按钮**：悬停时在原有绿/红底色基础上加深，不再变灰。
- **产物命名**：框架标识 `-WinUI` 移至平台标识之前，MSI 名为 `FileEncryptorGUI-<版本>-WinUI-Windows.msi`。
- **版本号**：升至 2.0.1，配套 CLI 期望版本 2.4.3。

### Fixed
- **MSI 构建**：修复 WiX v4 项目中 PublishDir 重复定义导致找不到输出文件的问题；安装包支持自定义安装路径、GPLv3 许可证、Windows Terminal 可选 Feature，安装结束页可直接启动 GUI。

## [GUI-WinUI 2.0.0] - 2026-09-26

Windows 侧界面从 Qt6 切换到 WinUI 3（Windows App SDK 1.5 / .NET 8），作为独立项目 `GUI-WinUI/` 存在。Linux 版本保持 Qt6，见 `GUI-Qt/`。

### Added
- **WinUI 3 界面**：布局与 Qt 版保持一致（菜单栏、文件列表、功能区、输出区、状态栏），全部功能无裁剪迁移。
- **文件勾选**：文件列表每项带勾选框，仅勾选的条目参与执行。
- **CLI 未找到提示**：启动时自动探测 CLI，未找到时弹窗列出预期文件名，可重试或前往下载。
- **自定义背景图**：视图设置中可选择图片作为主界面背景，也可随时清除恢复默认。
- **关于对话框**：分为「鸣谢」与「README 摘要」两页。
- **MSI 安装包**：WiX v4 打包，安装到 `%ProgramFiles%\FileEncryptor\`，含开始菜单与桌面快捷方式。
- **VS 解决方案**：根目录 `FileEncryptor.slnx`，VS2026 直接打开。

### Changed
- **背景统一为 Acrylic**：移除 Mica 选项。
- **主题精简**：删除浅色主题与切换选项，默认深色。
- **命令预览**：空闲时显示当前参数，运行时输出首行为完整命令；路径参数自动加引号。
- **加密模式下拉**：默认选中 XChaCha20-Poly1305，非对称项标注为「X25519 + ChaCha20-Poly1305（非对称）」。
- **版本号**：升至 2.0.0，配套 CLI 期望版本 2.4.2。
- **实现迁移**：CLI 调用从 `QProcess` 迁移到 `System.Diagnostics.Process`，密钥仍经 stdin 注入；进度帧解析、任务历史、密码强度、ETA 估算等逻辑从 C++ 移植为 C#。

### Fixed
- **对话框无响应**：修复任务历史、视图设置等对话框点击无响应的问题。
- **添加目录报错**：修复「添加目录」报无效窗口句柄的问题。
- **CLI 输出卡顿**：修复 CLI 输出捕获导致界面卡顿的问题，改为直接控制台执行。
- **按钮悬停配色**：修复按钮悬停颜色异常，运行按钮绿色、取消按钮红色且悬停加深。
