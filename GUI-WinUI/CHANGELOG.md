# ChangeLog - FileEncryptor GUI (WinUI 3 / Windows)

本文件记录 **FileEncryptor GUI (WinUI 3)** 子项目的变更。Linux Qt6 版本的变更记录见 [`../GUI-Qt/CHANGELOG.md`](../GUI-Qt/CHANGELOG.md)，CLI 见 [`../CLI/CHANGELOG.md`](../CLI/CHANGELOG.md)，自动更新器见 [`../Updater/CHANGELOG.md`](../Updater/CHANGELOG.md)。

格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [GUI-WinUI 2.1.2] - 2026-10-03

配套 CLI 期望版本 2.7.1。本版本新增自动清理旧版命令行程序与就地下载入口，并修好了检查更新在部分网络环境下必然失败的问题。

### Added

- **自动清理旧版命令行程序**：命令行程序的文件名里带版本号，每装一次新版目录里就多一份，都留着白占地方。现在每次探测到命令行程序时会把目录里版本号低于目标版本的那几份删掉，同版本与更新的版本一律不动，你手动换过的版本也不会被误删。
- **找不到命令行程序时可以就地下载**：未检测到时弹窗里在「重试」与「关闭」之间多了一个「下载 CLI」，自动认与本 GUI 配套的确切版本，下到程序目录并校验完整性，不用自己去 GitHub 翻。
- **打包为单个容器**：选项行新增「打包为单个容器」，把一整个目录树或一批文件收进单个 `.ptd`，解密时自动展开回原来的目录结构。源文件不动。
- **命令行问「是否继续」时弹窗询问**：命令行遇到「是否覆盖已存在文件」这类询问，以往界面这边没人应答，任务会直接以退出码 1 秒退。现在界面读出命令行具体在问什么，弹窗把选项摆出来，你答完它接着跑 —— 控制台模式与重定向模式都一样。
- **删源目录前先问一句**：输入里有目录、又选了删除 / 安全擦除 / 移至回收站时，运行前会列出待删目录请你确认（超过 5 个折叠成「另有 N 个」）；取消就什么都不做。选「保留源文件」时不会有任何打扰。
- **分卷输出**：选项行新增「分卷输出」，勾上后填分卷大小、单位（MB / GB / TB 任选），密文会切成 `.001`、`.002` 这样的多卷，方便塞进 FAT32、邮件附件或分段上传；解密时随便挑一卷都行，程序自己把同组的卷找齐合并。默认不勾，行为和以前一样。
- **老版本命令行程序不再被「打包」坑到**：「打包为单个文件」此前是不管三七二十一直接发给命令行程序的，遇到不支持的旧版本就撞上「未知参数」，任务白跑。现在启动探测时先问一句它支不支持，不支持就把这个勾选框灰掉并取消勾选。

### Fixed

- **命令行要答案时不再自己判成拒绝**：口令是通过标准输入喂进去的，写完就把输入通道关了；命令行随后想问你一句是否继续，读到的却是「没有输入」，于是当成你答了「否」并退出。界面与命令行之间现在改走一条独立的应答通道，问答不再受口令通道影响。

### Fixed

- **检查更新不再必然失败**：此前证书吊销检查过严，在拦吊销列表的网络环境下所有 HTTPS 请求都握手失败，界面只显示「检查失败：network_failed」；现在改用系统证书库并放宽吊销检查，同时自动沿用你在系统里设置的代理。
- **预览解密的中文不再乱码**：预览是边收边显示的，一个汉字正好被切成两半送到界面，此前每一块都单独解码，切在汉字中间的那块就变成一串问号。现在跨着块接着解码，完整显示。
- **水印私钥不再明文摊在临时目录里**：用了「签名水印」又往密码框里粘私钥时，私钥会落一个临时文件。现在这个文件收紧到只有当前用户能读、且用完即删；每个任务各自一份，不会互相覆盖（将来并行跑多个任务也不会拿错钥匙）。唯一残留风险是程序被强杀或崩溃，那一刻来不及删。
- **切换加密 / 解密时滚动条不再莫名消失**：在加密与解密之间来回切，选项区右侧的滚动条有时会自己不见，再切一次又好了。现在每次切换后都重新算一遍布局，滚动条老实待着。
- **「删源目录」的提示改得和实际动作一致**：实际删的是目录里的文件、目录本身留着（默认输出到源目录时密文就落在目录里，目录也不会空），提示却写成「源目录将被删除」，容易让人以为整棵目录树连根拔起。现在如实说明「源目录中的文件将被……（目录本身保留）」。

## [GUI-WinUI 2.1.1] - 2026-10-02

配套 CLI 期望版本 2.7.1。本版本新增预览解密，主题切换收进「视图」菜单并跟随系统，窗口底改用 Mica，找不到 CLI 时可直接下载，浅色模式的混排问题一并修掉；另补齐英文与俄文界面的漏翻文案，修正长文本横排溢出与下拉框回落成中文的问题。

### Added

- **预览解密**：文件列表旁新增「预览...」，选好密文后弹出口令，在新窗口里看到内容前若干字节，不必真的解密出文件；支持「下一个文件」连续查看，字节数可调。
- **主题切换收进「视图」菜单**：不再每次启动都强制深色，改为「视图 → 主题」里选浅色 / 深色 / 跟随系统，选择即生效并记住；任务历史与任务汇总弹窗也跟着换配色。
- **窗口底改用 Mica**：此前试过 Acrylic，实际效果是窗口整体发黑、几乎不透底，改用系统的 Mica 材质，透出桌面壁纸而不糊成一片。背景调节项从「视图」菜单移除，不再给用户一堆难以预期的旋钮。
- **找不到 CLI 时可以直接下载**：未检测到命令行程序时，弹窗里在「重试」与「关闭」之间多了一个「下载 CLI」，自动认与本 GUI 配套的确切版本，下到程序目录并校验完整性，不用自己去 GitHub 翻。

### Changed

- **后量子开关不再误报**：命令行程序不支持时，「后量子 PQC」勾选框会自动关闭，不会再向它发送不认识的选项。
- **含特殊字符的路径不再被改写**：控制台方式运行命令行程序时，参数逐项写入临时脚本再执行，路径里的 `%`、`!`、`&` 等字符保持原样。
- **多收件人临时文件更稳**：写入失败会直接取消任务并说明原因，不会把含逗号的原文当作收件人列表发出去。
- **国庆配色柔和了**：各层底色的明度差收窄，靠描边而不是靠色相分层，红底上的白字也更清楚；跟随系统时按系统实际的深浅取色。

### Fixed

- **浅色模式不再黑白字混排**：主题在界面加载前就定好，之前一半控件换配色、一半仍取旧值；对话框与任务汇总也跟随所选主题，不再一律深色。
- **红底上的字看得见了**：运行/取消按钮与勾选框的强调色文字保持白色，之前被刷成国旗红，变成红底红字。
- **英文 / 俄文漏翻补齐**：后量子密码、使用 X448 曲线、签名水印、水印签名密钥、私钥 PEM 提示、压缩级别等文案补上英 / 俄译文。
- **鼠标悬停提示跟随当前语言**：此前提示文字写死成中文，切换语言后不跟着变。
- **英文下拉框里的选项回落到中文**：下拉框的本地化分支被通用分支抢先匹配，已调整顺序。
- **长文本不再横着顶出窗口**：英文 / 俄文下动作、密钥管理、选项三行改为上下排列并换行显示。
- **中文弱口令不再被放行**：此前只要含非 ASCII 字符就直接判为合格，重复同一汉字的口令也能通过；现在非 ASCII 只算一类字符，全同字符口令一律拒绝，与 Qt 版判定一致。
- **任务历史收紧到仅本人可读**：历史目录此前沿用继承权限，现在目录与文件都改为仅当前用户可访问，与 Qt 版一致。

## [GUI-WinUI 2.1.0] - 2026-10-02

配套 CLI 期望版本 2.7.0。本版本把后量子密码、签名水印、SM4-GCM 与 X448 曲线接进界面，修正了一批选项显示、命令预览与布局问题，界面与 Qt 版保持一致，版本号一并升到 2.1.0。

### Added

- **后量子开关**：「选项」行新增「后量子 PQC」勾选框，默认开启——非对称收件人改用「X25519 + ML-KEM-768」混合密钥，水印签名改用 ML-DSA-65；取消勾选则回到经典 X25519 / X448 + RSA 路径。当前 CLI 不支持时该勾选框自动关闭。
- **签名水印**：新增「签名水印」勾选框，勾选后出现签名密钥行（密码框 + 浏览按钮），可粘贴密钥内容或读取密钥文件。不填密钥也能加密，只是写入未签名水印记录。
- **水印密钥不在界面上出现**：签名密钥在密码框中输入、不回显明文；命令预览里的密钥参数一律显示为 `<private-key>`，历史记录只存占位符，从历史恢复任务时需重新输入。
- **文件算法下拉**：选中「X25519 非对称」时，模式框右侧出现「文件算法：」下拉（XChaCha20-Poly1305 / AEGIS-256 / SM4-GCM），指定文件本身的加密强度，非对称部分只负责保护会话密钥。
- **SM4-GCM 算法**：加密模式下拉新增「SM4-GCM」。
- **使用 X448 曲线**：新增同名勾选框，勾选后非对称封装与「生成密钥对」改用 X448 曲线；解密时按容器内的收件人条目自动匹配，无需设置。
- **任务历史记录新增字段**：历史开始保存后量子、水印、水印密钥与文件算法，老记录按默认值读取，从历史恢复任务时一并还原。
- **下载 CLI 入口**：「CLI 未找到」对话框与工具菜单均可按当前版本拉取配套 CLI，下载后校验 SHA256 并自动替换，完成后重新探测。

### Changed

- **选项区改为横向勾选框排列**：后量子、使用 X448、签名水印与「覆盖已存在文件」「生成校验单」同排，签名私钥独立成行，勾选后才出现。
- **加密模式统一写作「X25519 非对称」**：曲线由「使用 X448」勾选框决定。
- **动作与密钥管理互斥**：选中其中一组会自动清掉另一组的勾选，不会出现两个动作同时点亮。
- **参数下发顺序与命令预览格式**与 Qt 版一致，私钥参数一律遮蔽。
- **版本号升到 2.1.0**（配套 CLI 2.7.0）：程序集版本、推荐下载的 CLI 文件名与下载标签一并跟随。

### Fixed

- **命令预览不再显示私钥明文**：勾选签名水印并填入密钥（或「浏览…」读进来）后，预览与输出日志里原本跟着私钥正文，现在一律只显示 `<private-key>`。
- **窗口启动即退出**：勾选框初值改在代码里设置，XAML 不再写 `IsChecked`，避免解析 XAML 时失败；崩溃时的异常与调用栈写入 `crash.log`，下次启动可直接查看。
- **密钥管理三项下不再显示加密专属字段**：选「生成密钥对 / 口令派生 / 导出公钥」时隐藏加密模式、压缩、源文件处置、生成校验单与签名水印，并清掉对应勾选，CLI 不会收到对当前动作无意义的开关。
- **解密与批量解密下不再残留「加密模式」与「压缩」行**：两处改为整行收起（含标签与级别输入）。
- **非对称模式不再误用 SM4 参数**：此前模式索引错位，选到非对称却下发 `-m sm4`。
- **非对称模式现在也能压缩**：CLI 本就支持非对称压缩，此前界面把非对称排除在外。
- **构建前请保持工程目录干净**：工程目录下如果残留 `MainWindow.xaml` 一类的副本会被一并编译，构建前顺手清掉即可。
- **更新器起不来不再一直转圈**：检查请求 60 秒、下载 5 分钟未返回结果就中止更新器进程并提示；更新器进程本身起不来时立刻提示，不会干等它结束。
- **检查失败能看出原因**：网络不通、DNS 解析失败、连接超时、TLS 证书、GitHub 限流、找不到对应 release、下载域名未放行等情况各有对应说明，并附更新器返回的原始信息。
- **英文 / 俄文界面不再漏翻**：「后量子 PQC」「使用 X448」「签名水印」「水印签名密钥」及其提示、压缩级别标签此前仍显示中文，补齐中 / 英 / 俄词条后三语一致。
- **悬停提示跟着语言切换**：后量子、使用 X448、签名水印、文件算法的悬停说明此前不参与翻译，切换语言后照旧显示中文。
- **英文 / 俄文下文字不再被裁掉**：「动作」「密钥管理」「选项」三行控件在英文与俄文下比中文长得多，横排会超出卡片宽度；非中文界面改为逐行排列，文字完整可见，中文保持一行排开。
- **下载按文件大小校验**：从更新结果里取到的文件大小会一并传给更新器，落盘后比对，缺失 SHA256 时也不会把错误页当安装包。
- **MSI 的版本号跟着程序走**：安装包此前固定标成 2.0.1，和程序的 2.1.0 对不上。现在版本号只在 `installer/FileEncryptorGUI.Installer.wixproj` 里写一次，MSI 的版本号与安装文件名会一起跟着变。
- **更新器随安装包一起装进程序目录**：安装包里带上 Updater.exe，装完就能直接用「检查更新」，不用另外去拷一个更新器文件。

### Changed

- **安装包各装各的目录**：Qt 版装到 `FileEncryptor (Qt)`，WinUI 版装到 `FileEncryptor (WinUI)`，两个版本可以同时装在机器上互不覆盖；开始菜单按目录分开，桌面快捷方式各自带框架标注。
- **参数逐项传递与超时兜底**：调用更新器时参数按列表逐项下发，更新器起不来、没有输出或超时都会被捕获并提示，不会静默无反应。
