# ChangeLog - FileEncryptor for Android

格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [GUI-MAUI 1.1.0] - 2026-11-15

### Security
- 设置页补充审计日志说明：桌面端审计用哈希链与外部锚点，移动端不写审计日志；同步中英俄三语文案。

正式版（补齐水印签名与格式化加密库）。配套 CLI 3.1.1，versionCode 8。

### Added
- 大部分功能与桌面端一致，具体请见桌面端功能列表 `../GUI-Qt/CHANGELOG.md`。
- 视频边导边播：统一把视频导到临时明文文件边导边播，起播前预填末尾 8MB；空间不够或导出失败时自动退回库内直读。GB 级别的大视频不再等全量导出，播放结束或锁库即删临时明文。
- 局域网共享：加密库可临时在本机开 HTTPS 共享，限速、访问日志与锁库即停都齐全。
- 批量移动：底层提供一次刷新、逐项改名、一次提交的批量接口，几十个项目一起移动比逐项处理快得多，进度页逐项显示，切到后台也不会被误锁。
- 水印签名：加密时可附带签名水印（ML-DSA-65 后量子签名或 RSA-3072 签名），用你的私钥给密文签名；事后用「工具 → 校验水印」选 .ptd 并（可选）提供对方公钥即可校验来源与完整性，并查看机器 ID、时间戳、随机数等元数据。
- 格式化加密库：在库菜单的「格式化加密库」可一键清空库内全部文件与文件夹，库密码、身份与加密设置保持不变。

### Changed
- 口令策略最低长度从 8 位提高到 12 位（保留常见弱密码表、纯数字/纯字母拒绝），与桌面端及 CLI 3.2.0 对齐；强度不足仍允许显式确认后继续。
- 性能：主题与静态文案缓存、下拉选项复用、资源占用采样移到后台、体积格式化免分配；底层分片索引只重写受影响的目录，段缓存淘汰改为常数时间，预读窗口按文件大小自适应。锁库时仍会清空内存里的明文索引，这一项没有为速度让步。
